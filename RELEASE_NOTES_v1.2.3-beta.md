# Pool Pilot v1.2.3-beta

Version corrective sans modification de la structure générale de la carte.

- Ajout du bouton Mode Maintenance dans le Mode Expert.
- Réduction de la valeur ORP / chlore dans la jauge pour éviter les débordements.
- Déplacement de la barre de progression dans la ligne « Cycle du jour » du Mode Expert.
- Affichage des commandes Ouvrir / Arrêter / Fermer du volet dans le panneau Contrôle, configurées directement dans la carte.

### Correctif recommandations
- La fenêtre d'alerte affiche désormais le produit, le dosage, le motif et les consignes de contrôle lorsqu'une recommandation produit est active.
- Suppression du message générique lorsque les données de recommandation sont disponibles.
