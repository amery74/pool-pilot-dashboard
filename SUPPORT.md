# Support

Before asking for help:

1. Confirm that the Pool Pilot integration is installed and configured.
2. Check the Lovelace resource URL and ensure its type is **JavaScript module**.
3. Reload the browser or Home Assistant application after updating.
4. Confirm the Pool Pilot Dashboard and integration versions.

For reproducible bugs, open a GitHub issue using the bug report form and include screenshots, the card configuration with secrets removed, and browser console errors when available.
