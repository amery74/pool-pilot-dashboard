# Pool Pilot Dashboard v1.2.1-beta

## ✨ New features
- The card can now switch automatic filtration between centered placement and an authorized time window.
- Minimum start and maximum end times can be edited directly from the card.
- New Pool Pilot `select` and `time` entities are detected automatically and can also be selected manually in the card editor.

## 🐞 Bug fixes
- Fixed the missing card controls for the automatic-filtration time window.
- The settings panel now shows only the fields relevant to the selected placement mode.
- Fixed the central-hour entity selector to use the Home Assistant `number` domain.
