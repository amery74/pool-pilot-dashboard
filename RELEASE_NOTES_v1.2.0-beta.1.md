# Pool Pilot Dashboard v1.2.0-beta.1

Beta release for community testing.

## New

- History charts for temperature, pH and ORP/chlorine.
- 24 h, 7 day and 30 day periods.
- Advanced electrolyzer production and Boost controls.
- Automatic ORP/chlorine presentation from a Pool Pilot configuration entity.

## Fixed

- Compatibility alias for `custom:pool-pilot-dashboard-card`.
- Scroll position preservation during live state updates.
- YAML and storage dashboard compatibility.
